# สเปกปรับความเร็วแกลเลอรี

## เป้าหมาย

ทำให้แกลเลอรีงานแต่งเปิดได้รวดเร็ว แม้อัลบั้มมีรูปความละเอียดสูงจำนวนมาก รองรับการสร้างหลายอัลบั้ม และทำให้อัปโหลดรูปมากกว่า 20 รูปได้โดยไม่ค้าง

## จุดที่ทำให้ช้าในปัจจุบัน

- รูปในการ์ดแกลเลอรีโหลดไฟล์ต้นฉบับโดยตรง
- หนึ่งหน้าแสดงรูปที่เผยแพร่ทั้งหมดพร้อมกัน
- การอัปโหลดรอให้แต่ละไฟล์เสร็จก่อน จึงเริ่มไฟล์ถัดไป และส่งไฟล์ทั้งหมดผ่าน request เดียว
- ยังไม่มีหน้าจอสำหรับสร้างและจัดการอัลบั้มใหม่ใน Admin

## แนวทางออกแบบ

### การส่งรูปไปยังผู้ชม

ก่อนอัปโหลด เบราว์เซอร์จะย่อด้านยาวของรูปให้ไม่เกิน 2,560px และแปลงเป็น WebP คุณภาพ 85% เพื่อให้ไฟล์ที่เก็บบนเว็บไซต์มีขนาดเล็กลงตั้งแต่ต้น ผู้ดูแลยังคงเก็บไฟล์ต้นฉบับไว้ภายนอกเว็บไซต์ได้สำหรับงานพิมพ์

เพิ่มตัวช่วยสร้าง URL สำหรับแปลงรูปผ่าน Supabase Storage จาก URL เดิมของแต่ละรูป การ์ดในแกลเลอรีจะใช้ thumbnail แบบ WebP ขนาดเหมาะกับหน้าจอ ส่วน lightbox ใช้ไฟล์ WebP ขนาดเต็มที่ผ่านการย่อแล้ว

### การแสดงรูปทีละชุด

lightbox จะยังได้รับข้อมูลรูปทั้งหมด แต่จะแสดงการ์ดชุดแรก 24 รูปก่อน แล้วมีปุ่ม “โหลดรูปเพิ่ม” เพื่อแสดงชุดละ 24 รูปถัดไปโดยไม่ต้องดึงข้อมูลจากฐานข้อมูลซ้ำ ลดภาระการจัดวางหน้าเว็บ การถอดรหัสรูป และการรับส่งข้อมูลในช่วงแรก โดยยังคงโครงสร้างอัลบั้มเดิม

หน้า Admin ใช้หลักการเดียวกันกับรายการรูป เพื่อไม่เรนเดอร์การ์ดและระบบลากเรียงลำดับของทุกรูปในอัลบั้มพร้อมกัน

### การจัดการอัลบั้ม

เพิ่มส่วนจัดการอัลบั้มในหน้า Admin: สร้างอัลบั้มใหม่ กำหนดชื่อและคำอธิบายภาษาไทย/อังกฤษ เลือกอัลบั้มเพื่ออัปโหลด และจัดลำดับอัลบั้ม โครงสร้างฐานข้อมูลเดิมรองรับข้อมูลนี้อยู่แล้ว จึงไม่ต้องย้ายรูปเก่า

### ความเร็วในการอัปโหลด

ตรวจสอบและย่อรูปทั้งหมดในเบราว์เซอร์ก่อนเริ่มอัปโหลด แสดงขนาดก่อนและหลังย่อของแต่ละไฟล์ จากนั้นขอ URL อัปโหลดชั่วคราวจากเซิร์ฟเวอร์ แล้วอัปโหลดตรงไปยัง Supabase Storage พร้อมกันได้สูงสุด 3 ไฟล์ ซึ่งไม่ติดเพดานขนาด request ของ Server Action

เมื่ออัปโหลดสำเร็จ ระบบส่งเฉพาะข้อมูล metadata กลับไปบันทึกลงฐานข้อมูลในครั้งเดียว พร้อมแสดงความคืบหน้าและผลลัพธ์ของแต่ละรูป

### การจัดการเมื่ออัปโหลดผิดพลาด

หากรูปใดลดขนาดหรืออัปโหลดไม่สำเร็จ จะแจ้งชื่อรูปนั้นและไม่สร้างข้อมูลในแกลเลอรีสำหรับรูปที่อัปโหลดไม่สำเร็จ ส่วนรูปที่อัปโหลดสำเร็จจะถูกบันทึกไว้ตามปกติ จึงไม่ต้องอัปโหลดซ้ำ

## การทดสอบ

- ทดสอบการย่อรูปให้เป็น WebP ตามขนาดและคุณภาพที่กำหนด
- ทดสอบการสร้าง URL thumbnail และยืนยันว่า lightbox ใช้ URL สำหรับรูปขนาดเต็ม
- ทดสอบว่าครั้งแรกแสดงเพียง 24 รูป และปุ่ม “โหลดรูปเพิ่ม” แสดงรูปชุดถัดไป
- ทดสอบว่าการอัปโหลดจำกัดจำนวนไฟล์ที่ส่งพร้อมกันที่ 3 รูป และบันทึกข้อมูลรูปที่สำเร็จเพียงครั้งเดียว
- ทดสอบการสร้างอัลบั้มและเลือกอัลบั้มสำหรับอัปโหลด
